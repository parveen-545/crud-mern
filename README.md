# CRUD MERN Application

A full-stack CRUD (Create, Read, Update, Delete) application built using the MERN stack.

## 🚀 Tech Stack

- **Frontend:** React.js, Vite, Axios, CSS3
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (using Mongoose)

## 🛠️ Features

- **Create:** Add new items/records via a user-friendly form.
- **Read:** Fetch and display all records in real-time.
- **Update:** Edit existing data easily.
- **Delete:** Remove records safely from the database.

## 📦 Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```

2. Setup Backend:
   ```bash
   cd server
   npm install
   npm start
   ```

3. Setup Frontend:
   ```bash
   cd ../client
   npm install
   npm run dev
   ```
